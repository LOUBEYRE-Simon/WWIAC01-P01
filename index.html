Charte de Sécurité et d'Utilisation de l'IA

Groupe SIFA - Sécurité des Systèmes d'Information

En raison des risques cyber, l'accès aux IA est bloqué par défaut depuis le réseau interne, à l'exception des modèles listés ci-dessous. Le risque majeur ne réside pas dans l'outil, mais dans la nature des données exposées.

1. CLASSIFICATION ET RISQUE DES DONNÉES
Niveau de Donnée Description et données concernées Action autorisée
Données Critiques Données issues de GTrans, tarifs, listings clients, données financières, personnelles (RGPD) et code source. Exclusif aux outils validés (cf. Section 2)
Données Publiques Recherche générique, vulgarisation de concepts techniques, informations non confidentielles. Autorisé sous contrôle strict
2. INVENTAIRE DES OUTILS AUTORISÉS
A. Outils d'Entreprise (Données sous contrôle)
  • Microsoft Copilot Enterprise & M365 Copilot : Environnement étanche. Les données ne sont pas utilisées pour l'entraînement public.
  • OpenAI API & Groq : Usage technique exclusif aux serveurs EDI pour les développements et tests.
  • Gemini Pro : Dérogation spécifique pour le service Douane NC (en cours de remplacement).
B. Outils Publics sous Contrôle Strict

Mistral (leChat), ChatGPT, Claude, Gemini, Perplexity.

  • Tolérés uniquement pour des recherches ne contenant pas de données d'exploitation.
3. RÈGLES D'USAGE ET ACTIONS SURVEILLÉES
Ce qui est strictement interdit sur les outils publics :
  • Aucun document interne ou confidentiel (GTrans).
  • Aucun upload de fichier (PDF, Excel, images).
  • Aucun plugin ou extension de navigateur non audité.
  • Aucune autorisation d'accès persistante (micro, caméra, fichiers).
Monitoring :
  • Les flux sortants vers les services d'IA sont surveillés en continu.
4. CAS PRATIQUES
Cas 1 : Résumer ou analyser une opération logistique (GTrans)
✔ Outil recommandé : Microsoft Copilot.
Règle : Traitement autorisé en interne, car la confidentialité est garantie.
Cas 2 : Traduire un e-mail commercial (standard)
✔ Outil autorisé : Mistral ou ChatGPT (version publique).
Règle : Autorisé à condition de ne mentionner aucun nom de client ni données chiffrées.
Cas 3 : Développement informatique et tests EDI
✔ Outil autorisé : OpenAI API / Groq.
Règle : Utilisation via les serveurs EDI uniquement. Aucune donnée métier.
5. RESPONSABILITÉ ET VALIDATION

L'IA est un outil d'assistance à la décision. L'utilisateur reste seul responsable de l'exactitude du contenu. En cas de divergence avec l'IA, les données extraites du logiciel de gestion GTrans font foi.
